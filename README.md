# 🏠 AI Real Estate Intelligence Platform

An end-to-end AI-powered Real Estate Web Application built using FastAPI, Random Forest Regression, LangChain, ChromaDB RAG, and Groq LLM.

## Features
- **Data Analysis & EDA**: Automated visual inspection of real estate prices and property features.
- **Price Prediction**: Machine Learning regression model to estimate property values based on key attributes.
- **Property Recommendation**: Algorithmic matchmaker providing explainable property recommendations based on budget and layout.
- **Generative AI Assistant**: Conversational expert for market trends, buying tips, and real estate guidance.
- **RAG Knowledge Assistant**: Instant document QA over uploaded legal/buying guides.
